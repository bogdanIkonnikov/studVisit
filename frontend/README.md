# StudVisit Admin Panel

Админ-панель для управления системой учета посещений StudVisit.

## Возможности

- **Дисциплины**: добавление, редактирование, удаление дисциплин
- **Группы**: управление студенческими группами
- **Студенты**: добавление студентов, привязка к группам
- **Учителя**: управление преподавателями
- **Уроки**: создание расписания уроков, связь с учителями и группами
- **Посещения**: отслеживание посещаемости студентов

## Установка и запуск

### Локальная разработка

1. Перейти в папку фронтенда:
```bash
cd frontend
```

2. Установить зависимости:
```bash
npm install
```

3. Убедитесь, что бекенд запущен на `http://localhost:8080`

4. Запустить dev сервер:
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`

### Docker

Убедитесь, что вы находитесь в корне проекта и есть настроенный `.env` файл с переменными БД.

Запустить контейнеры:
```bash
docker-compose up --build
```

Приложение будет доступно по адресу `http://localhost:3000`

## Технологический стек

- **Vue 3** - фреймворк для фронтенда
- **Vue Router** - маршрутизация
- **Pinia** - управление состоянием
- **Axios** - HTTP клиент
- **Bootstrap 5** - UI фреймворк
- **Vite** - build tool

## API Endpoints

Панель взаимодействует со следующими endpoints бекенда:

- `GET /api/disciplines` - получить все дисциплины
- `POST /api/disciplines/add` - создать дисциплину
- `GET /api/groups/getAll` - получить все группы
- `POST /api/groups/add` - создать группу
- `GET /api/students/getStudentByGroupId/{id}` - получить студентов группы
- `POST /api/students/addStudent` - добавить студента
- `GET /api/teachers` - получить всех учителей
- `POST /api/teachers/add` - добавить учителя
- `POST /api/lessons/all/by-teacher` - получить уроки учителя
- `POST /api/lessons/add` - создать урок
- `POST /api/lesson-visits/add` - добавить посещение

## Переменные окружения


```
VITE_API_BASE_URL=http://studvisit-app:8080/api
```
